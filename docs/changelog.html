2026-08-05 — Delivery optimize default baked to ReleaseFast

fixBare standardOptimizeOption(.{}) shipped Debug

A bare standardOptimizeOption(.{}) returns Debug on a plain zig build. Debug materializes undefined as real bytes and once shipped a 68 MB archive.

Replaced with an explicit b.option(std.builtin.OptimizeMode, "optimize", ...) orelse .ReleaseFast, which keeps -Doptimize registered and bakes the correct default.

Classification: Pure-Zig

No Fortran under this layer, so the compute is the Zig and safety checks sit on the hot path rather than off it. ReleaseFast is therefore the right delivery default here, where ReleaseSafe is right for the Zortran libraries. wintermolt links ZERO forKernels archives at build time, so there is no Fortran anywhere under it.

Verified with zig build --help: -Doptimize=[enum] is registered and reports the ReleaseFast delivery default.
